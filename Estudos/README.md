# 🔬 Estudos — Inteligência de Mercado

> Base institucional de estudos de mercado, demografia, concorrência, tendências, benchmarks e cenários macroeconômicos que orientam a estratégia da Nexa Malls.

---

## 1. Objetivo

Sustentar a tomada de decisão da Nexa Malls com inteligência de mercado primária e secundária — produzindo, organizando e disseminando conhecimento sobre varejo, ativos comerciais, demografia e macroeconomia.

---

## 2. Estrutura

| Subpasta | Conteúdo |
|----------|----------|
| `Mercado/` | Estudos gerais de mercado imobiliário e varejista |
| `Demografia/` | Análises populacionais, renda, classes sociais |
| `Concorrencia/` | Mapeamento e análise de competidores |
| `Tendencias/` | Movimentos do varejo e do consumo |
| `Benchmark/` | Comparativos nacionais e internacionais |
| `Macroeconomia/` | Juros, inflação, política, crédito imobiliário |
| `Setor-Varejo/` | Análises setoriais (alimentação, saúde, conveniência etc.) |

## 4. Ferramentas Utilizadas

- **Dados públicos:** IBGE, RAIS, CAGED, Banco Central
- **Dados privados:** Geofusa, Cushman, JLL, Cyrela, ABRASCE
- **Geo:** Google Maps Platform, QGIS, Geofusa
- **Análise:** Python (pandas), Google Sheets, Excel, Looker
- **IA:** ChatGPT/Claude para síntese e crítica
- **Pesquisa web:** Bright Data, Nimble, Perplexity

---

## 5. Integrações

- **Estudos ↔ Viabilidade** — premissas alimentam modelos.
- **Estudos ↔ Comercial** — base de propostas técnicas.
- **Estudos ↔ Marketing** — insumo para conteúdo institucional.
- **Estudos ↔ IA RAG** — base documental para consultas.

---

## 6. Padrão Institucional de Estudo

Todo estudo deve conter:

1. **Sumário executivo** (máximo 1 página)
2. **Metodologia** — fontes, recorte temporal, premissas
3. **Dados** — tabelas, gráficos, mapas
4. **Análise** — interpretação dos dados
5. **Conclusões e recomendações**
6. **Limitações e ressalvas**
7. **Referências bibliográficas**
