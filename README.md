# Nexa-Growth

**Centro Operacional Digital — Nexa Malls & Planejarcomm**

> Repositório institucional para desenvolvimento imobiliário, gestão de ativos comerciais, automações, CRM, inteligência artificial, comercialização, operação, marketing, estudos de mercado e dashboards executivos.

---

## 1. Visão Geral

O **Nexa-Growth** é a espinha dorsal digital da Nexa Malls e da Planejarcomm. Reúne em um único repositório todos os processos, automações, prompts de IA, templates comerciais, estudos de viabilidade, integrações e dashboards executivos que sustentam a operação de desenvolvimento e gestão de strip malls em escala nacional.

Este repositório foi concebido sob arquitetura limpa, escalável e modular — pensado como o sistema operacional de uma proptech imobiliária de alta performance.

---

## 4. Princípios Arquiteturais

1. **Single Source of Truth** — todo ativo digital nasce e vive aqui.
2. **Modularidade** — cada pasta opera de forma independente, mas conectada ao todo.
3. **Padronização** — nomenclaturas, templates e fluxos seguem padrões institucionais.
4. **Escalabilidade** — projetado para crescer de 1 para 100 ativos sob gestão.
5. **Documentação como Código** — toda decisão operacional é registrada em Markdown.
6. **Automação por Princípio** — tarefas manuais são candidatas naturais a workflows.
7. **IA-First** — inteligência artificial é embutida em cada etapa da operação.

## 6. Como Começar

1. Leia este README na íntegra.
2. Consulte `/Documentacao/Onboarding/` para o roteiro de ambientação.
3. Explore o glossário em `/Documentacao/Glossario/`.
4. Antes de criar um novo ativo, busque template em `/Projetos/Templates-Projeto/`.
5. Para automações novas, registre em `/Automacoes/n8n/workflows/`.
6. Para novos prompts de IA, adicione em `/IA/Prompts/` na categoria correta.
